# 약물 트레이닝

[사이트 열기](https://vitality0914.github.io/drug-study/)

403개 약물로 연습하는 세 가지 모드입니다.

- **약물명 타자연습**: 이름을 보고 따라 쓰기
- **약물명 타자실전**: 특징을 보고 해당 약물 N개 입력하기
- **약물 꼬맨틀**: 유사도와 순위를 따라 정답 찾기

실전은 239개 특징 문제이며 기본 표현은 한영 혼용입니다. 연습·실전은 무작위 순서가 기본이고 코드 순서도 선택할 수 있습니다. 꼬맨틀 기본 난이도는 Easy입니다.

유사도는 약리학 대·중·소분류 35%, 최신 검수 특징 문구 40%, 작용 기전·임상 용도·부작용·상호작용 25%를 비교합니다. 문자 TF-IDF/로컬 LSA 근사를 사용하며 약물명 철자는 점수에서 제외합니다.

별도 서버나 로그인 없이 작동하는 정적 웹사이트입니다. 웹폰트 라이선스는 assets/fonts/LICENSE.txt에 있습니다.
